## 2024-06-03 - Credential Exposure in Process Lists via Git URLs
**Vulnerability:** Embedding tokens directly into Git remote URLs (e.g., `https://x-access-token:${token}@github.com/...`) exposes them to the system's process list (`ps aux`). Both `simpleGit` and direct `spawn` calls execute `git` child processes with the URL as a command-line argument.
**Learning:** Any secret passed as a command-line argument to a child process becomes visible system-wide to any user with sufficient permissions to read process lists. This is a critical risk, especially in CI/CD or shared environments.
**Prevention:** Instead of embedding credentials in the URL, use Git's credential helper system injected securely via environment variables. Configure the remote with a generic URL and use `git -c credential.helper=...` or `simpleGit`'s `config` array along with `.env({ SECRET: token })` to pass credentials to the helper securely.
